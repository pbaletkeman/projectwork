# Phase 6 - AI Companion

## Objective

Introduce an AI-powered ring companion.

The companion provides:

- Lore
- Hints
- Guidance
- Mission summaries

The companion must not be required to complete the game.

---

## Features

Add:

- Chat interface
- Context awareness
- Memory of completed bosses
- Memory of discovered locations

Example:

Player:

"How do I open the Crystal Gate?"

Companion:

"You obtained the Light Grapple in the Crystal Caverns.
Try exploring above the gate."

---

## Technical Goals

Learn:

- LLM APIs
- Prompt Engineering
- Conversation History
- Embeddings

---

## Restrictions

No voice support.

No generated quests.

No generated game content.

Only assistance.

---

## Resume Goal

Built AI-assisted NPC companion using LLMs and contextual game state.
